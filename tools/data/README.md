# 图片下架登记

`image_takedowns.json` 保存已确认下架图片的机器可读身份与指纹，不依赖会被清理的 output 报告。当前仅为登记册，导入器、上传器和发布/回滚工具尚未统一读取它，不能把文件存在当作自动防复入已生效。方案见本地 docs/roadmap.md「图片下架防复入」。

- `cases[].status: active` 表示下架决定有效；撤回决定应保留历史并显式变更状态。
- `members[].scope: entry` 表示整条下架；`image_member` 只对应该成员的 key/hash，不封禁仍保留其他图片的整条词条。
- `assets[].sha256` 是该精确文件完整字节的 SHA-256，`kind` 区分原图与展示图；不是 R2 ETag 或 assetRev。
- 改名不改变字节哈希；重新压缩或修改元数据会改变哈希。像素/感知哈希尚未回填。
- 只保存简短原因码，不放作者联系方式、申诉原文或图片提示词。详细证据保存在本地案件归档。
- 本登记册是私有维护数据，原路径由根 `.gitignore` 精确忽略，不纳入公开仓库或发行包。维护代码可以入库，实际记录单独私有保存；不能随站点数据 release 回滚到旧名单。
- 换机器时须另行迁移最新登记册并校验完整性；Git 不承担它的备份。未来公共读取器遇到缺失或损坏必须阻断，不能当成空名单。
